# 🎈 CRM Backoffice - Locação de Festas

> Sistema de gestão interna (Mobile-First PWA) para controle de locação de kits de mini festas, gestão de estoque e emissão inteligente de contratos digitais.

## 🚀 Funcionalidades Principais
- 📦 **Gestão de Kits:** Composição dinâmica e controle de peças únicas.
- 📅 **Controle de Agenda:** Bloqueio automático de datas por limite de estoque.
- ✍️ **Contratos Digitais:** Geração automática de PDF e link de aceite via WhatsApp.

## 🛠️ Como rodar o projeto localmente

### Pré-requisitos
- Node.js (v22+)
- Banco de dados PostgreSQL (local ou URL em nuvem)

### Instalação
1. Clone o repositório:
`git clone https://github.com/SEU_USUARIO/backoffice-festas.git`

2. Instale as dependências do Back-end:
`cd backend && npm install`

3. Instale as dependências do Front-end:
`cd frontend && npm install`
